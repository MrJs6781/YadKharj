# یادخرج

اپ اندروید برای ثبت دلیل واریز و برداشت‌های بانکی از روی پیامک.

## ساخت APK بدون اندروید استودیو
1. در github.com یک ریپوی جدید بساز (Private هم اوکیه).
2. فایل زیپ رو از حالت فشرده دربیار و محتویاتش رو توی ریپو آپلود کن (Add file ← Upload files).
   - پوشهٔ `.github` مخفیه. اگه آپلود نشد: Add file ← Create new file و اسم فایل رو بنویس:
     `.github/workflows/build.yml` و محتوای فایل هم‌نامش رو توش پیست کن.
3. تب Actions ← «Build APK» ← Run workflow (یا خودکار بعد از آپلود اجرا می‌شه).
4. حدود ۵ تا ۸ دقیقه بعد، از پایین صفحهٔ اجرا، فایل `YadKharj-APK` رو دانلود کن، زیپش رو باز کن و `app-debug.apk` رو روی گوشی نصب کن.

## بعد از نصب
در تب «تنظیمات» سه دسترسی (پیامک، اعلان، نمایش روی سایر برنامه‌ها) رو فعال کن و با «ارسال پیامک آزمایشی» تست بگیر.
روی بعضی گوشی‌ها (شیائومی، سامسونگ، ...) باید برای اپ «Autostart» رو روشن و محدودیت باتری رو خاموش کنی.
